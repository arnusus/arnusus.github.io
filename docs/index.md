# نصوص يهودية بالعربية

مكتبةٌ لترجمة النصوص الدينية اليهودية الكلاسيكية إلى العربية عن أصولها العبرية والآرامية، بلغةٍ فصيحة على طريقة كتب التفسير والأدب التراثي، مع هوامش تشرح ما قد يجهله القارئ العربي.

</div>
